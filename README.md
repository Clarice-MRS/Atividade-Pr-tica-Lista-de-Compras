#  Listaê!

Projeto desenvolvido com o objetivo de criar um sistema de lista de compras, praticando conceitos Front-End e lógica de programação com JavaScript.

Permite criar e organizar uma lista de forma dinâmica, utilizando JavaScript para manipular os elementos da página.

## Instruções

1. Clone o repositório:
 
```
git clone https://github.com/Clarice-MRS/Atividade-Pr-tica-Lista-de-Compras.git
```

2. Abra o arquivo `índex.html` em um navegador web.

##  Funcionalidades

-  Adicionar itens à lista
-  Editar itens
-  Remover itens
-  Marcar itens como comprados

## Requisitos entregues

**Obrigatórios**

- [x] Adicionar um item à lista (nome do produto; opcionalmente quantidade e categoria).
- [x] Remover um item da lista.
- [x] Marcar/desmarcar um item como "comprado", com feedback visual claro.
- [x] Exibir a lista de itens de forma organizada e legível.
- [x] Impedir a inclusão de itens inválidos (ex.: nome vazio) — prevenção de erros.

**Desejáveis (para nota extra / desafio)**

- [ ] Filtrar itens (todos / pendentes / comprados).
- [x] Contador de itens (total, comprados, restantes).
- [x] Editar um item já cadastrado.
- [ ] Persistir os dados (ex.: localStorage) para não perder a lista ao recarregar.
- [x] Layout responsivo (funciona bem em celular e desktop).

## Justificativa de Framework

Optou-se por não utilizar frameworks nem bibliotecas front-end devido a maior familiaridade com o JavaScript nativo e para não extrapolar a complexidade do projeto.
